## 🛠️ Regenerating Reports with the CLI

To re-run the crawl and regenerate reports:

```bash
# Re-crawl all code AST usages
gcs-optics crawl-code --all \
  --output-csv reports/fsspec_crawl_results.csv \
  --output-json reports/combined_fsspec_report.json \
  --output-md reports/combined_fsspec_report.md

# Regenerate matrix and summary tables
gcs-optics matrix --input-json reports/combined_fsspec_report.json --output-md reports/method_distribution_matrix.md
gcs-optics summary --input-json reports/combined_fsspec_report.json --output-md reports/all_methods_summary_table.md

# Re-crawl GitHub issues
gcs-optics crawl-issues --all \
  --output-csv reports/all_issues.csv \
  --output-json reports/all_issues.json \
  --output-md reports/all_issues.md
```
